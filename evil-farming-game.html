The Evil Farming Game

A remembered game about a farmer with a dark secret, searched for and never found. The likely answer is a memory blend.

The claim

A Reddit user described remembering a game in which the player runs a farm and, at some point, discovers a body or commits a murder, with the game turning dark. The description was detailed enough to start a search, and no game matching it was found.

Maps, diagrams and images

The outcome

The search produced candidates — games with farming and dark themes — and no match. The consensus is that the memory is a blend of several games and possibly a creepypasta, which is a common outcome for childhood memories of media.

The archive files it as documented because the search is a real, recorded event, and the game is not established.

What is established

Documented: the memory and the search.

Documented: the candidates considered.

Not found: any matching game.

Likely: a memory blend.

The label: documented, with the game unestablished.

Why it is in the archive

Because it shows what the failure mode looks like when the search is honest about not finding it.
