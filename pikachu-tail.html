Pikachu's Tail

A generation remembers Pikachu with a black tip on its tail. It has never had one, and the false memory is a textbook case.

The claim

The claim, circulating since the 2010s, is that Pikachu's tail has a black tip in the early games and anime, and that it has since been removed — or, in the stronger version, that reality has changed. It is filed with the Berenstain Bears and other 'Mandela effect' cases.

Maps, diagrams and images

The answer

Pikachu's tail has always been plain yellow with a brown patch at the base, shaped like a lightning bolt. The black-tipped tail belongs to Pichu, the pre-evolution, and to some other Pokémon. The confusion is a memory blend between related characters, reinforced by the number of fan drawings that add a tip.

The check is trivial: any official artwork, any game sprite, any plush toy.

What is established

Documented: the design, in official material since 1996.

Documented: the black-tipped tail on Pichu.

Explained: by blending related characters in memory.

Not established: any change to the design.

The label: debunked.

Why it is in the archive

Because it is the cleanest modern false-memory case, and because the object of the memory is checkable in a second.
