The Topic Register

The five collections name 830 topics between them. The archive has 508 dossiers. This page lists the rest — 726 topics that are named, labelled and summarised, but have no page yet. It is the work queue, and it is the map that stops the archive writing the same dossier twice.

Each row keeps the label the collection gave it, so a new dossier starts with its verdict already argued. Nothing on this page is a claim that the topic is unwritten forever; twelve of these became dossiers in November 2026, and the rows that did were removed from this list rather than duplicated.

Grouped by collection, then by the collection's own theme, then by row number. The match between a collection topic and a dossier is by title, so a handful of rows are covered by a dossier under another name — the count is a work queue, not an audit. Check this page before proposing a dossier: if the topic is here, it is not written; if it is not here, search the archive first.
