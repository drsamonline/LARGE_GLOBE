Reading paths

Twelve ways into the archive.

A thousand dossiers is not a reading list. These are twelve short sequences, six pages each, chosen so that the argument builds rather than repeats — and every one of them can be read in a sitting.

If you only have twenty minutes, take the first trail. If you want to know how the archive decides anything, take the second and the fifth together.

Start with the argument the archive is named for. Each page takes one version of the claim seriously enough to test it, and the sequence ends where the evidence does.

Begin with the three theories that share a name but not an argument. Then the strongest version, and the one with the most careful proponents. The ice wall is the version with the least evidence and the most certainty. End on the sky, because the same reasoning is used there.
